# Primer ingreso

1. Abra HCOP JP desde el acceso directo.
2. Ingrese con el usuario y la contraseña elegidos durante la instalación.
3. La pantalla inicial muestra una hoja clínica en blanco.
4. Use **Nuevo paciente** para crear una historia o **Abrir paciente** para
   buscar una existente.
5. El paciente abierto queda asociado solamente a su sesión.

No comparta usuarios. Cada evolución, suspensión, escaneo QR y finalización se
registra con el usuario activo.

Después del primer acceso:

- cambie la contraseña si se usó la sugerida;
- cree roles y usuarios desde **Configuración**;
- configure cantidad de sillones, horario y fracción de turnos;
- revise protocolos y duraciones;
- configure el LLM solo si se utilizará.
