# Glosario

| Término | Significado en HCOP JP |
|---|---|
| HCOP | Historia Clínica Oncológica en formato de hoja clínica. |
| Hospital de Día | Circuito que integra prescripción, farmacia, sillón y administración. |
| Tratamiento | Prescripción longitudinal asociada a diagnóstico y protocolo. |
| Ciclo | Repetición numerada de un tratamiento, con fecha y logística propias. |
| Aplicación / turno | Reserva real de un ciclo en fecha, hora y sillón. |
| Protocolo / esquema | Definición reusable de drogas, preparación, tiempos y periodicidad. |
| Lista de espera | Ciclos pendientes de asignación de sillón, ordenados por fecha clínica. |
| Logística | Estado de prescripción y disponibilidad de medicación por ciclo. |
| Continuidad | Condición activa, suspensión transitoria o finalización del tratamiento. |
| Evolución | Entrada clínica inmutable que documenta un acto o decisión. |
| Hoja blanca | Documento JSON versionado que conserva la presentación clínica narrativa. |
| Paciente activo | Paciente abierto únicamente en la sesión del usuario actual. |
| Revisión | Número usado para evitar que una escritura pise otra más reciente. |
| QR clínico | Código firmado que identifica paciente, tratamiento, ciclo y turno. |
| Catálogo | Datos locales de referencia: AJCC, TNM, SNOMED, CIE-10, drogas o guías. |
| Configuración versionada | Definición editable que conserva sus revisiones históricas. |
| RBAC | Acceso por roles y permisos, comprobado en el servidor. |
| Flyway | Mecanismo que crea y evoluciona PostgreSQL con migraciones ordenadas. |
| OpenAPI | Contrato generado de la API; Swagger lo presenta y permite probarlo. |
| Lira compatible | Contrato visual o HTTP heredado, implementado completamente de forma local. |
